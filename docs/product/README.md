# Product

Product and business notes: where the app could go beyond its current use. Technical decisions live in [`docs/adr/`](../adr/) and the domain glossary in [`CONTEXT.md`](../../CONTEXT.md). This folder covers the *why* and the *for whom*.

Every document keeps three things apart:

- **Decisions**: agreed on. Changing one takes a new conversation, which gets recorded.
- **Hypotheses**: ideas that seem reasonable but nobody has validated yet. Don't build on them as if they were facts.
- **Open questions**: what is still unresolved.
